# Loja Virtual — documentação (TCC)

Documentação da loja virtual desenvolvida como Trabalho de Conclusão de Curso: uma plataforma de comércio eletrônico em PHP e MySQL em que cada lojista tem sua própria loja, integrada ao sistema de gestão, com pagamento por PagBank/PayPal e frete pelo Melhor Envio.
